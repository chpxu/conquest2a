Roadmap
=======

This page serves as a rough idea as to what I hope to implement in the library moving forward. Features listed here may/may not ever make it into the core and I provide no timeline for implementation.

- Further ASE integration. May be difficult as this library aims to keep track of species numbers.
- Covering more CONQUEST features: current CONQUEST has an MDAnalysis script - I believe that the utilities presented in this library (especially regarding densities, pDOS and Band structure) can be used by the CONQUEST community
